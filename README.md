# كناش الحوت Pro — مشروع Android

هاد المشروع كيلفّ نسخة HTML ديال كناش الحوت داخل تطبيق Android باستعمال WebView. البيانات المحلية اللي كيحفظها التطبيق كتظل فبيانات التطبيق على نفس الهاتف؛ دير نسخة احتياطية من داخل الموقع إلا كانت خاصية النسخ الاحتياطي متوفرة.

## استخراج APK بلا Android Studio

1. فكّ الضغط على ZIP.
2. أنشئ Repository جديد فـ GitHub، ورفع **محتويات** هاد المجلد ليه.
3. دخل لتبويب **Actions** ووافق على تفعيل Actions إلا طلب منك.
4. اختار **Build Android APK** ثم **Run workflow**.
5. من بعد ما يسالي البناء بنجاح، حلّ نتيجة التشغيل (workflow run) ونزّل **Kanach-Lhout-Pro-APK** من قسم **Artifacts**.
6. فكّ ضغط الملف المنزّل، وغادي تلقى `app-debug.apk` ثبّتو فالهاتف.

## ملاحظات
- هادي نسخة Debug للتجربة والتثبيت الشخصي، ماشي إصدار متجر Play موقّع بمفتاح نشر خاص.
- التطبيق كيحتاج الإنترنت لبعض الخطوط والأيقونات الخارجية اللي كتحمّلها صفحة HTML.
- جرّب الوظائف المهمة وخذ نسخة احتياطية من البيانات قبل الاعتماد عليه يومياً.
